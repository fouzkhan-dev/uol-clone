# University of Layyah — Website Clone (Unofficial Demo)

**Unofficial educational demo clone** of the University of Layyah website,
built from scratch (original HTML/CSS/JS) to mirror the public site's layout
and public information. **Not affiliated with, endorsed by, or connected to
the University of Layyah.**

- Official website: https://ul.edu.pk/
- Live demo: see the Vercel deployment link in the repo description / below.

## What's inside (v2 — multi-page)

- `index.html` — homepage: hero photo slider (9 real homepage photos), stats
  (5 faculties, 22 departments, 62 programs, 6858 students), features, Vice
  Chancellor's message with photo, faculties, programs, admissions, top stories
  with photos, contact.
- `about.html` — Vision & Goal, Mission, Goals, Core Values.
- `admissions.html` — admission status notice, how to apply, eligibility, fee
  structure, merit lists, ECAT.
- `faculties.html` — all 5 faculties, with Faculty of Computing & Engineering
  detail (Dean Dr. Muhammad Amjad, departments, programs).
- `news.html` — Top Stories (MOU with UET, Day Care Center, 5th Syndicate
  Meeting, visit of VC Thal University Bhakkar).
- `contact.html` — address, email, phone, demo contact form.
- `assets/img/` — photos from the official site (ul.edu.pk), used in this
  educational demo only.
- `styles.css` — original stylesheet (green + gold university theme).
- `script.js` — mobile menu, animated stat counters, hero slider.

## Notes

- The university crest is represented by a simple "UL" monogram (not the
  official logo).
- A visible disclaimer banner stays on every page of the demo at all times
  so no visitor mistakes it for the official site.
