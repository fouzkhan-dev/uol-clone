# University of Layyah — Website Clone (Unofficial Demo)

**Unofficial educational demo clone** of the University of Layyah homepage,
built from scratch (original HTML/CSS/JS) to mirror the public site's layout
and public information. **Not affiliated with, endorsed by, or connected to
the University of Layyah.**

- Official website: https://ul.edu.pk/
- Live demo: see the Vercel deployment link in the repo description / below.

## What's inside

- `index.html` — homepage: header, hero, stats (5 faculties, 22 departments,
  62 programs, 6858 students), Vice Chancellor's message, faculties,
  programs, admissions, top stories, contact.
- `styles.css` — original stylesheet (green + gold university theme).
- `script.js` — mobile menu + animated stat counters.

## Notes

- Photos from the official site were **not** copied; image areas use CSS
  gradients. The university crest is represented by a simple "UL" monogram.
- A visible disclaimer banner stays on the demo at all times so no visitor
  mistakes it for the official site.
- Audit step (pending): review against Apple design principles with the
  `apple-design` skill, on the owner's word.
